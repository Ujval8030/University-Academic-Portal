# University-Academic-Portal
A web-based University Academic Portal that allows students to access academic information, view attendance, check examination results, manage course details, and stay updated with university announcements through a simple and user-friendly interface.


# University Academic Portal

A student-friendly web application designed to manage
academic information in one place.

## Features
- Student Dashboard
- Course Information
- Attendance Details
- Examination Results
- University Announcements

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Run index.html in your browser.
